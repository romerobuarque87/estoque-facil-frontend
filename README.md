# Estoque Fácil

Projeto front-end desenvolvido com HTML, CSS e JavaScript para controle de estoque.

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Edição de produtos
- Exclusão com confirmação usando SweetAlert2
- Pesquisa por nome ou código
- Validação de campos obrigatórios
- Cálculo do valor total do estoque
- Indicação de estoque baixo
- Salvamento local no navegador com localStorage

## Como executar

Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
